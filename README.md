# Sleep Tracker Analyzer

Приложение для анализа данных о сне на основе логов с умных часов.

## Функционал
- Подсчёт общего числа сессий сна.
- Расчёт минимальной/максимальной/средней продолжительности сессий.
- Анализ качества сна (количество сессий с качеством «BAD»).
- Определение бессонных ночей (00:00–06:00 без сна).
- Классификация хронотипа пользователя («Жаворонок», «Сова», «Голубь»).
